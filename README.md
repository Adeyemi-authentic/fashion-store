# FlyFit

> **Concept build.** FlyFit is a fictional Lagos fashion brand. Payments run in Paystack **test mode** and product images are **AI-generated**. This is not a real store.

An AI-native fashion store built to show two things: backend system design (concurrency, payments, async jobs, caching, observability) and AI features that are measured with real numbers (hybrid search, recommendations, a tool-using shopping assistant, a content pipeline).
